# A71 touch investigation, 2026-10-22

## Observed on this handset

The handset boots iOS to the lock screen, according to its owner. It is
currently in TWRP. Read-only ADB inspection confirms:

- `sec_touchscreen` on `a84000.i2c`, address `1-0048`.
- ID read by TWRP: `53 45 37 71 00` (Samsung y771).
- Touch coordinate maxima: 4095 / 4095; display maxima: 1079 / 2399.
- Touch functions in TWRP: `0061`; its firmware updater skips updating.
- Recovery logs contain actual press and release events.

The previous XNU persistent log was read from the final 1025 4-KiB blocks
of userdata, using the owner's `tools/pull_log.py`. It shows:

```
SWEET TOUCH: bus pins SDA(6)=0 SCL(7)=0 RST(8)=1 IRQ(9)=0
SWEET TOUCH: probe 0x48 (one_event) err=60 ev0=00 ev1=00
SWEET TOUCH: probe 0x48 (sec_ts ID) err=60 id='????'
SWEET TOUCH: no supported IC (goodix=0 fts=0 sec_ts=0 dead=0); stopping
```

Other probed addresses also time out. This is a transport/initialization
failure before HID reporting. It is not evidence of missing controller
firmware. The exact reason for GENI failing is still unconfirmed.

The prior patch 0082 removed the check of `GENI_IF_FIFO_DISABLE_RO` at
offset 0x64. The Linux `i2c-qcom-geni.c` runtime-resume path uses GSI when
this register is nonzero. Its value was not recorded in the previous XNU
log, so GSI-only mode remains a hypothesis, not a finding.

## Candidate patch 0083

- Optional `sweettouchbitbang=1` uses GPIO6/7 in open-drain mode and bypasses
  GENI clock/engine initialization. It implements repeated START, ACK/NACK,
  bounded clock stretching, STOP and line release on errors. Default remains
  the existing GENI path, with an added FIFO-disable diagnostic.
- GPIO mapping is checked against `pinctrl-sdmmagpie.c`: NORTH = TLMM +
  0x500000, WEST = TLMM + 0x100000. The similarly named sm6150 driver has
  different tiles and must not be used as the reference.
- Correct continuous scaling of raw 0..4095 into native 0..1079/2399.
  The former conditional scaling caused a discontinuity within the screen.
- Deliver coordinate events while draining the queue, preserving a press
  and release that occur in one FIFO batch.
- Require the observed y771 identity rather than accepting any I2C ACK.
- Set touch functions `0x0061` before SENSE_ON and check both operations.
- Read a full 16-byte event during probing, matching the y771 event format.

The bitbang path is an unverified bring-up alternative. It may fail if the
lines are held low, GPIO access is restricted, or power setup is incorrect.
It does not establish the root cause of the GENI timeout. Existing 0082
power/reset behavior is retained and still needs hardware validation.
